# meshcall-demo-py2ts-client

Generated MeshCall TypeScript client package.

```bash
yarn install
yarn build
```

```typescript
import { PythonGreetingServiceClient, PythonGreetingServiceGreetRequest, GreetingResult } from "meshcall-demo-py2ts-client";
```

The parent demo's `uv run demo` command uses `run.mjs` to call the generated
client against the Python service.
